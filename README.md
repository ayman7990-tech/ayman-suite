# 🎛️ Ayman Termux Suite

لوحة تحكم موحدة لكل تطبيقاتك على Termux.

## ✨ المميزات
- 🎛️ لوحة موحدة لكل التطبيقات
- ▶️ تشغيل بضغطة زر
- 🛑 إيقاف آمن
- 🌐 فتح في المتصفح
- 📊 إحصائيات حية
- 📱 واجهة متوافقة مع الجوال

## 🚀 التثبيت

pkg install python
pip install flask
git clone https://github.com/ayman7990-tech/ayman-suite.git
cd ayman-suite
python suite.py

افتح: http://localhost:7500
